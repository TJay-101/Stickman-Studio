# Stickman Studio

A beginner-friendly, browser-based stickman animation studio.

## Run it
Open `index.html` in a modern browser (Chrome recommended). No drawing or installation is required.

## First episode
Episode 01, **The Mysterious Energy**, is included. Use Play to preview the animation. Use **Record video** and then **Stop & save** to export a WebM video to your device.

## Notes
- The first version is a simple visual prototype with generated stickman animation.
- It does not yet include voice narration, background music, multiple episodes, or MP4 export.
- For YouTube, upload the saved WebM file if accepted by your upload workflow, or convert it to MP4 with a trusted video editor.

## Next improvements
Add editable story scenes, narration, sound effects, character customization, and higher-quality video export.
